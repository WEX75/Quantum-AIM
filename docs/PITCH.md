# Pitch (3 minute, 5 slide-uri)

1. **Problema** — o frază + de ce contează (ex: „QML pe hardware NISQ pierde acuratețea din cauza zgomotului”)
2. **Ideea noastră** — o diagramă a pipeline-ului
3. **Rezultatul** — un singur grafic, un singur număr mare (ex: „96.7% vs 51% la p=0.1”)
4. **De ce e corect** — baseline clasic, param count, seed-uri, limitări
5. **Ce urmează** — hardware real, alt dataset, alt model de zgomot

_Fiecare afirmație = un număr din `make summary`._
